# Nexora Digital | Agency Landing Page 🟠

A modern, conversion-focused landing page for a digital agency. It presents services, process, pricing, client testimonials, FAQs and a working contact form, all in a responsive dark glass design.

**Live Demo:** https://agency-landing-page-taupe-kappa.vercel.app/

> Replace the link above with your actual Vercel link.

---

## 📌 The Problem

Many small businesses and startups have a great product idea but no clear online presence. Their website is either outdated, slow, or does not explain what they offer, so visitors leave without contacting them.

## ✅ The Solution

This landing page is built to turn visitors into clients:
- A strong hero section with clear call-to-action buttons
- Services and a step-by-step process that explain the value
- Transparent pricing with a highlighted "Most Popular" package
- Social proof through testimonials
- FAQs that remove common objections
- A contact form that pre-selects the package the visitor clicked

---

## ✨ Features

- 🧭 **Sticky Navbar** with glass effect on scroll and mobile menu
- 🚀 **Hero Section** with headline, CTAs and key stats
- 🧩 **Services Grid** with 3D tilt cards
- 🔄 **Process Section** (Discover, Build, Launch)
- 💰 **Pricing Packages** with a highlighted "Most Popular" plan
- ⭐ **Testimonials** section
- ❓ **FAQ Accordion** (no JavaScript library needed)
- 📩 **Contact Form** with package pre-selection and success message
- 🎞️ **Scroll Reveal Animations**
- 📱 **Fully Responsive** on mobile, tablet and desktop

---

## 🛠️ Tech Stack

- **HTML5** and **CSS3** (Tailwind CSS via CDN, custom styles)
- **Vanilla JavaScript** (no framework)
- **Lucide Icons**
- **Inter** font (Google Fonts)
- **Vercel** for hosting
